# مجمع النور التجاري - حاسبة منظومات الطاقة الشمسية
تطبيق ويب متكامل لحساب تكاليف وعروض أسعار منظومات الطاقة الشمسية بالدينار العراقي وفق الهوية البصرية الرسمية لمجمع النور التجاري.

## الميزات البرمجية:
1. **واجهة متجاوبة وأنيقة:** متوافقة 100% مع الهواتف الذكية، الأجهزة اللوحية (iPad)، والشاشات المكتبية.
2. **منطق التقسيط المعتمد:** يحدد الزبون مبلغ الدفعة المقدمة بنفسه، ثم يضاف تحميل 40% على المبلغ المتبقي فقط، ويقسم المبلغ الناتج على 18 شهراً ثابتة.
3. **الدفع النقدي أو الأقساط:** عند اختيار النقد يظهر السعر النهائي دون تحميل، وعند اختيار الأقساط تظهر تفاصيل المقدمة والمتبقي والتحميل والقسط الشهري.
4. **خدمة الربط:** يستطيع الزبون اختيار المنظومة مع ربط أو بدون ربط، وأسعار الربط قابلة للتعديل من لوحة الإدارة.
5. **تصدير وطباعة عروض الأسعار الرسمية:** دعم مباشر لتوليد فواتير وعروض أسعار جاهزة للطباعة والتصدير كـ PDF مع ترويسة مجمع النور، جداول تفصيلية، خانات التوقيع والختم.
6. **لوحة الإدارة والتحكم (Admin Portal):** إمكانية ضبط وتحديث أسعار الصرف، أجور اليد العاملة، وتكاليف الهياكل مع حفظ التعديلات في LocalStorage دون الحاجة لخادم خلفي.
7. **المشاركة عبر واتساب:** تحويل نتائج الحساب تلقائياً إلى رسالة منسقة وجاهزة للإرسال على WhatsApp.
